# Tvheadend Konfigurator
Legt die Instanzen der Tvheadend-Bibliothek an. Er hängt am Gateway und zeigt, was der Server hergibt: je einmal Server, Tuner, DVR, EPG, Aufnahmeregeln, EPG-Kachel, Streaming, Kanalverwaltung und Diagnose, dazu eine Gruppe mit allen Netzwerken des Servers. Vorhandene Instanzen erkennt er und zeigt ihre ID.

## 1. Konfiguration

Der Konfigurator hat keine Einstellungen. Die Liste zeigt in einer Spalte "Name" und "Beschreibung":

Eintrag | Beschreibung
------------ | ----------------
Server, Tuner, DVR, EPG, Aufnahmeregeln, EPG-Kachel, Streaming, Kanäle, Diagnose | Je eine Instanz pro Gateway. Eine Zeile mit "Erstellen" legt sie an, vorhandene zeigen ihre ID.
Netzwerke | Gruppe mit einer Zeile je Netzwerk des Servers (zum Beispiel DVB-S oder IPTV), mit Anzahl Muxe und Services. Je Netzwerk entsteht eine Instanz. Die Gruppe erscheint nur mit einem Administrator-Benutzer.

## 2. Variablen

Der Konfigurator legt keine Variablen an.

## 3. Funktionen

Der Konfigurator hat keine Funktionen für Skripte.
